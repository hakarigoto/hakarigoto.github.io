年賀状の文例とマナー

賀詞・本文・日付の並べ方と、相手別にそのまま使える文例をまとめます。ここで扱うのは公式の決まりではなく、一般に言われている慣習です。

更新日:2026年9月23日執筆:はかり
30秒でわかるこの記事のポイント
  • 年賀状は賀詞 → 添え書き → 日付の3つで構成します。順番を守るだけで形になります。
  • 「賀正」「迎春」のような短い賀詞は、目上の人には使わないとされています。目上には「謹賀新年」など四字の賀詞を使うのが一般的です。
  • 「去年」は避けて「昨年」「旧年」と書く、句読点を使わない、といった慣習があります。
  • 自分または相手が喪中のときは年賀状を出さず、別の形であいさつします。

年賀状の基本構成

年賀状の文面は、次の順に並べるのが基本の形とされています。

順番要素例
1賀詞(新年のあいさつ)謹賀新年 / あけましておめでとうございます
2お礼・お願いの言葉旧年中は大変お世話になりました
本年もよろしくお願い申し上げます
3相手を気づかう言葉・近況皆様のご健康とご多幸をお祈り申し上げます
4日付令和九年 元旦

「元旦」は1月1日の朝を指す言葉です。そのため「一月一日元旦」と書くと意味が重複するとされ、「令和九年 元旦」または「令和九年一月一日」と書くのが一般的です。

賀詞の使い分け

賀詞は文字数によって意味の重みが変わるとされ、相手によって使い分けるのが慣習です。

種類例一般に言われている使い方
一字寿 / 賀 / 福目上の人には使わないとされる
二字賀正 / 迎春 / 賀春同じく目上の人には避けるとされる。「正月を迎えました」という事実を述べた形で、敬意や祝意の言葉が含まれないため
四字謹賀新年 / 恭賀新年 / 敬頌新禧「謹」「恭」「敬」といった敬意を表す字が入るため、目上の人に使えるとされる
文章あけましておめでとうございます
謹んで新年のお慶びを申し上げます		相手を選ばず使いやすい。迷ったらこの形が無難とされる

賀詞は重ねて使わないのも慣習です。「賀正 あけましておめでとうございます」のように二つ並べると、同じ意味を繰り返すことになります。

英語の「A Happy New Year」については、文中でなければ冒頭の「A」は付けないとされます。「Happy New Year」が単独のあいさつとして正しい形です。

相手別の文例

そのまま書き写して使える形で挙げます。賀詞・本文・日付の順に並べてあります。

上司・目上の人へ

謹賀新年
旧年中は格別のご指導を賜り誠にありがとうございました
本年も変わらぬご指導のほどよろしくお願い申し上げます
皆様のご健康とご多幸を心よりお祈り申し上げます
令和九年 元旦

取引先へ

謹んで新年のお慶びを申し上げます
旧年中は格別のご高配を賜り厚く御礼申し上げます
本年もより一層のご愛顧を賜りますようお願い申し上げます
皆様のご繁栄を心よりお祈り申し上げます
令和九年 元旦

職場の同僚へ

あけましておめでとうございます
昨年はいろいろと助けていただきありがとうございました
本年もどうぞよろしくお願いします
令和九年 元旦

友人へ

あけましておめでとう
昨年は会えてうれしかったです
今年もまた時間をつくって会えたらうれしいです
令和九年 元旦

親戚へ

あけましておめでとうございます
旧年中はお世話になりありがとうございました
本年もどうぞよろしくお願いいたします
皆様お元気でお過ごしくださいますようお祈りしております
令和九年 元旦

長く会っていない相手へ

あけましておめでとうございます
ごぶさたしておりますがお変わりありませんか
こちらは家族そろって元気に過ごしております
本年もどうぞよろしくお願いいたします
令和九年 元旦

避けたい言葉・書き方

避けたいもの理由として言われていること言い換え
去年「去る」が別れを連想させるため昨年 / 旧年
句読点(、。)「区切りをつけない」という意味合いと、もともと毛筆の文書に句読点を使わなかった名残改行や空白で区切る
忌み言葉滅びる・枯れる・失う・倒れる・病むなど、年始のあいさつにふさわしくないとされる語使わない
賀詞の重複同じ意味を二度述べることになるため賀詞は一つだけにする
「A Happy New Year」の A単独のあいさつとしては冠詞が不要とされるためHappy New Year

また、印刷した文面だけで送ることは失礼にあたらないとされますが、一言だけ手書きを添えると印象が変わると言われます。次の項で触れます。

一言添えるときの考え方

手書きの一言は、長く書く必要はありません。相手と自分の間にあった具体的な出来事に触れると、定型文との差が出ます。

  • 会った記憶がある相手 — 「昨秋はお声がけいただきありがとうございました」
  • 仕事で世話になった相手 — 「〇〇の件では大変助けていただきました」
  • しばらく会えていない相手 — 「今年はぜひお会いしたいです」
  • 相手に子どもがいる — 「〇〇ちゃんの入学おめでとうございます」

相手の状況がわからないときは、健康や繁栄を願う一般的な言葉にとどめるほうが安全です。

喪中のときはどうするか

自分が喪中の場合は年賀状を出さず、年賀欠礼のあいさつ(喪中はがき)を、相手が年賀状を用意し始める前に出すのが一般的とされています。

相手が喪中とわかっている場合は、年賀状を送らないのが通例です。年始のあいさつをしたい場合は、松の内が明けてから寒中見舞いとして出す形がよく用いられます。

喪中はがきの文面は、喪中はがき 文例ジェネレーターで続柄と時期を選ぶだけで作成できます。
